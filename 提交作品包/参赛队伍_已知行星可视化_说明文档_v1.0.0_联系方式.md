# 01 项目概述

## 项目简介

**已知行星可视化** 是一款桌面端三维 / 二维宇宙行星可视化软件，将太阳系天体（八大行星、冥王星、13 颗天然卫星）、NASA 完整目录中的 6375+ 颗真实系外行星（归并为 4781 个恒星系）以及 62 颗 Hipparcos 真实亮星，按真实天文数据呈现在统一空间中。软件支持 Blender 式自由视角操作，并能在选中两颗行星后计算并查看它们之间的相对运动轨迹。

启动器提供 **3D 立体视图 / 2D 平面视图** 两种模式；除三维轨道空间外，还提供双行星相对运动分析、天象推演（冲日/合日/大距/方照/行星合相/凌日）、系外行星观测特征（凌星光变/视向速度/宜居带）、观测者地面视角与任意天体地表第一人称全景等分析与观测能力。

## 目标

- **科学可视化**：以真实、客观的天文数据为基础，将已知行星呈现在同一个空间
- **专业交互**：对标 Blender 3D 视口的操作体验，降低天文可视化工具的上手门槛
- **教育价值**：提供开普勒定律等预设教学场景，支持科普教育用途
- **分析能力**：双行星相对运动轨迹分析、天象推演与观测特征分析，填补现有工具的功能空白

## 适用场景

- 天文爱好者探索太阳系与系外行星
- 中小学/大学天文课程教学演示
- 科普场馆/科技馆互动展示
- 天文科普创作者素材获取
- 初级科研人员数据可视化辅助
- 科幻创作者/游戏设计者参考

# 05 使用说明

## 软件整体功能

已知行星可视化软件提供以下核心功能：

1. **启动器（模式选择）**：入口先选择「3D 立体视图 / 2D 平面视图」（快捷键 3 / 2），两个主窗口可随时切换模式
2. **三维主视口**：太阳系 + 系外行星的真实三维位置与轨道渲染，含程序化表面贴图、体积星云背景、主带小行星带点云、行星环与自转轴
3. **二维平面视口**：QPainter 俯视黄道面的轨道图，自适应网格环、春分点方向、比例尺
4. **Blender 式视角控制**：轨道模式/飞行模式，数字键盘视图切换
5. **天体搜索与浏览**：搜索栏 + 左侧恒星系（系群）天体树，支持中/英文名称
6. **天体详情面板**：轨道根数、物理参数、自转周期与转轴倾角、发现信息、精度等级
7. **双行星相对运动分析**：轨迹曲线、距离/速度曲线、4 种参考系
8. **测距工具**：任意两天体间距离测量与连线
9. **天象推演**：冲日 / 合日 / 大距 / 方照 / 行星合相 / 凌日六类事件，结果可点击跳转时间轴
10. **观测特征**：系外行星凌星光变曲线 + 视向速度曲线 + 宜居带三联图
11. **地面视角**：指定观测点的地平天球星空图、太阳日轨与日出日落/暮光事件
12. **地表视角**：站在任意天体表面的第一人称全景，昼夜天光渐变、真实视星等亮度
13. **时间控制**：播放/暂停/倒放/9档倍速/日期跳转
14. **尺寸对比工具**：真实直径比例并排展示
15. **教学场景**：6个预设场景一键播放（开普勒定律等）
16. **新手引导**：7步引导教程，首次启动自动弹出

## 常见问题 FAQ

**Q: 为什么有些系外行星的瞬时位置标注"假设值"？**
A: 系外行星的平近点角（M）通常未测定，我们取 M(J2000)=0 的可复现假设值。轨道形状和周期是真实的，但沿轨道的瞬时位置是假设的。

**Q: 为什么真实比例模式下天体几乎看不见？**
A: 真实比例下行星半径极小（地球仅约 0.00004 AU），这是物理事实。软件以最小标记点显示，切换到可视化比例可放大观察。

**Q: 为什么时间超出 1800-2050 年范围会警告？**
A: JPL 近似轨道根数在该范围外误差随时间累积，软件主动提示精度下降。

## 精度分级依据

### A 级（高精度）

**定义**：轨道根数与物理参数均来自权威源（JPL），三维位置可靠。

**覆盖**：太阳系八大行星 + 冥王星 + 太阳 = 10个天体

**依据**：
- 轨道根数来自 JPL Standish 近似（精度优于1角分）
- 物理参数（半径/质量）来自 NASA Planetary Fact Sheet
- 位置计算使用世纪变率修正（T = (JD-J2000)/36525）

### B 级（中精度）

**定义**：有轨道倾角测定（凌星法），三维位置较可靠。

**覆盖**：有倾角数据的系外行星

**依据**：
- 凌星法可测定轨道倾角 i，从而确定轨道平面方向
- 半长轴 a 和偏心率 e 来自径向速度(RV)或凌星观测
- 但平近点角 M 未测定，取假设值 M(J2000)=0

### C 级（低精度）

**定义**：缺轨道倾角或相位数据，瞬时位置为假设值。

**覆盖**：无倾角数据的系外行星（RV/成像法发现）

**依据**：
- RV法只能测定 a×sin(i) 和 e，无法确定真实倾角
- 成像法虽有倾角但精度有限
- 轨道形状和周期可靠，但三维方向不确定
- 平近点角 M 取假设值 M(J2000)=0

| 字段 | 太阳系行星 | 系外行星（后备子集） | 系外行星（默认完整目录） |
|------|-----------|---------------------|---------------------|
| 半长轴 a | 100% | ~95% | ~85% |
| 偏心率 e | 100% | ~80% | ~60% |
| 轨道倾角 i | 100% | ~40% | ~15% |
| 公转周期 | 100% | ~95% | ~90% |
| 行星半径 | 100% | ~60% | ~30% |
| 行星质量 | 100% | ~50% | ~25% |

| 发现年份 | 100% | 100% | 100% |

## 数据校验方法

1. **数值合法性**：NaN/负数/超出物理范围的值自动标记为缺失（None）
2. **缺失字段处理**：一律显示"未知"，禁止伪造或插值
3. **坐标系一致性**：所有坐标统一到 J2000 黄道坐标系，赤道坐标经黄赤交角旋转转入
4. **可复现性**：系外行星平近点角取 M(J2000)=0（非随机数），保证同一输入永远得到同一输出
5. **与 JPL Horizons 对比**：太阳系行星位置可与 JPL Horizons 在线服务对比验证

## 系外行星平近点角假设说明

系外行星的平近点角（M）通常无法从观测数据中确定（除非有完整相位覆盖的凌星或 RV 数据）。本软件取 **M(J2000) = 0** 的可复现假设值：

- **影响**：仅影响行星沿轨道的瞬时位置（即"现在在轨道哪个点"），不影响轨道形状（a, e, i）和周期
- **不影响的**：轨道半长轴、偏心率、倾角、公转周期、行星半径/质量
- **可复现性**：同一输入参数永远产生同一输出（非随机数），便于科学验证
- **标注**：所有系外行星详情面板中标注"轨道相位: 假设值（M(J2000)=0，可复现）"

# 09 局限性与风险声明

## 已知局限

### 1. 系外行星瞬时位置为假设值

**局限**：系外行星的平近点角（M）通常未测定，本软件取 M(J2000)=0 的可复现假设值。

**影响范围**：所有系外行星（默认 6375+ 颗完整目录；CSV 缺失时回退 76 颗后备子集）

**不影响**：轨道形状（a, e, i）、公转周期、行星物理参数

**说明**：瞬时位置仅表示"假设该行星在 J2000 时刻处于近心点"，实际位置可能相差半个轨道。但轨道形状和周期是真实的，相对运动分析（会合周期、距离变化趋势）仍然有效。

### 2. JPL 近似星历适用范围

**局限**：太阳系行星使用 JPL Standish 近似轨道根数，适用范围为 1800–2050 年。

**超出范围**：误差随时间累积，软件主动弹出警告提示。

**替代方案**：需要更高精度或更长时间范围时，应使用 JPL Horizons 在线服务或 DE440 星历表。

### 3. 系外行星缺轨道倾角

**局限**：约60%的系外行星（RV法发现）缺乏轨道倾角测定，三维轨道方向不确定。

**影响**：这些行星标注为 C 级精度，轨道线在三维空间中的方向是假设的（取 i=0，即黄道面内）。

**不影响**：轨道形状（a, e）和周期。

### 4. 可视化比例 vs 真实比例

**局限**：默认可视化比例模式下，天体半径放大1000倍以便观察。

**说明**：HUD 明确标注"半径已放大1000倍，距离为真实值"。切换到真实比例模式可查看真实大小关系（但天体极小，以标记点显示）。

### 5. 地球使用地月质心轨道

**局限**：地球位置使用 EM Bary（地月质心）轨道根数，而非地球单独轨道。

**依据**：JPL 表中地球条目即为 EM Bary，这是天文惯例。地月质心与地球中心差距约 4670 km（约 0.00003 AU），在可视化尺度下不可见。

### 6. 系外行星宿主星自行忽略

**局限**：系外行星宿主恒星的位置取 J2000 时刻的静态位置，不考虑自行（proper motion）。

**影响**：近距离恒星（如 Proxima Cen）在数千年尺度上位置变化可达数角秒，但在可视化尺度下不可见。

### 7. 单精度浮点渲染

**局限**：OpenGL 渲染使用 float32，跨18个数量级的尺度需要浮点原点偏移策略。

**已处理**：CPU 端以相机眼点为局部原点（float64），相对坐标转 float32 上传，避免精度爆炸。

### 8. 非地球天体地表经度零点为假设值

**局限**：除地球外，其他天体的本初子午线角常数项未收录，地表视角统一取 W(J2000)=0 的可复现假设值（地球直接取 GMST，与观测者地平坐标互校一致）。

**影响**：仅影响地表视角中"经度零点"的朝向，不影响自转速率、自转方向与星空的相对运动。

### 9. 小行星带与表面贴图为程序化生成

**局限**：主带小行星带（约 5 万颗）按真实分布特征（半长轴区间、柯克伍德空隙、倾角聚集）程序化生成，非逐颗实测轨道；行星表面贴图同样为着色器程序化生成（确定性噪声），非真实影像。

**说明**：小行星带采用固定随机种子，结果可复现；表面贴图按自转轴定向、随自转相位推进，用于提升视觉真实度，不作为科研测量依据。

## 科学诚实性原则

本软件遵循以下科学诚实性原则：

1. **缺失数据标"未知"**：不伪造、不插值、不猜测
2. **精度分级标注**：每个天体标注 A/B/C 级及原因
3. **假设值标注**：系外行星相位假设明确标注
4. **适用范围提示**：超出星历范围主动警告
5. **比例模式提示**：HUD 明确标注当前比例模式
6. **数据来源标注**：详情面板显示每个天体的数据来源

# 10 码道使用说明

## 概述

本项目全程使用 **华为云码道 CodeArts 代码智能体** 辅助开发，从项目搭建到最终打包，覆盖完整开发生命周期。

## 分阶段使用记录

### 阶段1：项目搭建与数据层

**使用方式**：向码道描述需求（天体数据模型、坐标系约定、精度分级），码道生成完整的数据层代码。

**码道生成内容**：
- `core/constants.py`：物理常数、单位换算、精度分级 A/B/C 定义
- `core/time_system.py`：儒略日换算（Fliegel-Van Flandern 算法）、仿真时钟
- `core/kepler.py`：开普勒方程牛顿迭代求解、JPL 根数→三维位置、轨道采样
- `core/relative_motion.py`：4参考系相对运动计算、会合周期
- `data/solar_system.py`：JPL 近似轨道根数+世纪变率
- `data/exoplanets_builtin.py`：76颗真实系外行星精选子集（后备）
- `data/asteroid_belt.py`：主带小行星点云生成
- `data/stars_builtin.py`：62颗真实亮星表
- `data/loader.py`：Body 统一模型、坐标转换、数据校验

**人 + AI 分工**：
- 人：确定数据源（JPL/NASA/Hipparcos）、精度分级标准、坐标系约定
- 码道：生成代码实现、数值验证、边界处理

### 阶段2：三维主视口与 Blender 视角

**使用方式**：向码道描述 Blender 视角操作规范（中键旋转/Shift+中键平移/滚轮缩放/Numpad视图），码道生成相机与渲染代码。

**码道生成内容**：
- `scene/camera.py`：轨道相机+飞行模式+阻尼+聚焦动画+书签
- `scene/viewport.py`：OpenGL 3.3 Core 渲染管线（着色器/VBO/浮点原点/拾取/HUD）

**关键 bug 修复**：
- PyQt5 的 QOpenGLBuffer 枚举名是 `VertexBuffer` 不是 `ArrayBuffer`（PySide 命名差异）
- PyQt5 的 `allocate()` 不接受 bytes，需 `allocate(len) + write(0, bytes, len)` 两步

**人 + AI 分工**：
- 人：确定 Blender 操作规范对标、浮点原点策略
- 码道：生成着色器代码、处理 PyQt5 API 差异、调试 GL 问题

### 阶段3+4：轨迹增强与双行星对比

**使用方式**：向码道描述相对运动分析需求（4参考系/精度分级/曲线图），码道生成对比面板。

**码道生成内容**：
- viewport 增补：历史尾迹、对比连线、轨迹筛选 API
- `ui/style.py`：Blender 深色主题 QSS
- `ui/compare_panel.py`：matplotlib 图表（3D轨迹/2D俯视/距离速度曲线/时间游标）

**关键 bug 修复**：
- 质心参考系 + 缺质量数据 → TypeError：码道定位并修复为诚实回退恒星参考系
- matplotlib 默认字体无中文：码道配置 rcParams 中文字体

### 阶段5：UI框架

**使用方式**：向码道描述主窗口布局（三栏分拆/工具栏/时间轴/天体树），码道生成完整 UI 框架。

**码道生成内容**：
- `ui/timeline.py`：时间轴控件
- `ui/tree_panel.py`：天体树面板
- `ui/main_window.py`：主窗口组装
- `ui/detail_panel.py`：详情面板
- `ui/size_compare.py`：尺寸对比工具

### 阶段6：新手引导与教学场景

**使用方式**：向码道描述引导流程和教学场景需求，码道生成引导对话框和场景预设。

**码道生成内容**：
- `ui/guide.py`：7步新手引导
- `ui/teaching_scenes.py`：6个预设教学场景

### 阶段7：天象推演与观测特征

**使用方式**：向码道描述天象事件（冲日/合日/大距/方照/合相/凌日）判定规则与系外行星观测特征需求，码道生成解析计算与面板。

**码道生成内容**：
- `core/phenomena.py`：地心视黄经/距角解析计算，扫描+变号二分/黄金分割求根
- `core/exo_obs.py`：凌星光变、视向速度 K、Kopparapu 2013 宜居带
- `ui/phenomena_panel.py` / `ui/exo_obs_panel.py`：结果表与三联图

**关键 bug 修复**：

### 阶段8：二维平面视图与启动器

**使用方式**：向码道描述二维俯视轨道图与双模式入口需求，码道生成二维视口与启动器。

**码道生成内容**：

- `ui/launcher.py`：3D / 2D 模式选择启动器

### 阶段9：地表视角与星云背景

**使用方式**：向码道描述任意天体地表第一人称观测与程序化星云需求，码道生成相应计算与渲染代码。

**码道生成内容**：
- `core/observer.py`：观测者地平坐标与日出日落/暮光
- `core/surface.py`：任意天体地表视角（天顶方向/局部地平系/视星等亮度）
