## ✨ 功能亮点

### 🌌 真实三维宇宙

- **太阳系**：八大行星 + 冥王星 + 13 颗天然卫星，含真实轨道、自转轴、行星环

- **系外行星**：6375+ 颗真实系外行星，归并为 4781 个恒星系，来自 NASA 官方目录

- **背景星空**：8 万+ 颗 Hipparcos 真实亮星按三维位置分布

- **引力系统**：用弯曲网格直观呈现 M/r 引力势，感受时空弯曲

### 🎮 Blender 式交互

- 中键旋转 / Shift+中键平移 / 滚轮缩放，对标 Blender 3D 视口操作

- 飞行模式（WASD + QE）自由漫游宇宙

- 数字键盘快速切换正/侧/俯视图

- 天体搜索树，中英文名称一键聚焦

### 📊 分析与观测

- **双行星相对运动**：4 种参考系（A/B/质心/恒星），距离/速度曲线、3D 轨迹

- **天象推演**：冲日、合日、大距、方照、行星合相、凌日六类事件自动计算

- **系外行星观测特征**：凌星光变曲线 + 视向速度曲线 + 宜居带三联图

- **地面视角**：指定观测地点的地平星空图、太阳日轨、日出日落与暮光

- **地表视角**：站在任意天体表面的第一人称全景，昼夜天光渐变

### 🔬 科研计算面板

覆盖从观测数据到物理建模的完整科研链路：

| 模块          | 功能                                            |
| ----------- | --------------------------------------------- |
| **FITS 数据** | 纯自研解析器（无需 astropy），支持图像定标、孔径测光、宇宙线剔除、光谱去噪与归一化 |
| **RV 拟合**   | χ² 周期图 + 开普勒轨道反演，输出 K/P/e/ω/T₀/γ ± 1σ，相位折叠图   |
| **凌星星历**    | 线性星历拟合 + O−C 图（TTV 分析入口）                      |
| **恒星与大气**   | 主序质量-光度-半径关系、黑体光谱、平衡温度、大气标高、临边昏暗凌星光变          |

### 🎓 教学与入门

- 6 个预设教学场景：开普勒三定律、火星合相、TRAPPIST-1 系统等

- 7 步新手引导，首次启动自动弹出

- 精度分级 A/B/C 标注，数据可靠性一目了然

- 尺寸对比工具，真实直径比例并排展示

## 🚀 快速开始

### 方式一：直接运行（推荐）

下载打包好的 `.exe`，双击即可运行，无需配置环境，内置数据离线可用。

### 方式二：从源码运行

```bash
# 克隆或解压源码
cd Astrarium

# 安装依赖
pip install PyQt5 numpy scipy pandas matplotlib

# 启动软件
python main.py
```

### 方式三：一键安装脚本（Windows）

双击 `install.bat`，自动检测环境、安装依赖、创建启动快捷方式。

### 启动模式

- **3D 立体视图**（快捷键 `3`）：三维轨道空间主视图

- **2D 平面视图**（快捷键 `2`）：俯视黄道面轨道图

- **引力系统**（快捷键 `G`）：时空弯曲网格视图

也可命令行直接进入：`python main.py 3d|2d|gravity`

## 🎯 精度说明

数据按可靠性分为三级，每个天体均有标注：

| 等级      | 含义  | 覆盖                     | 精度                                |
| ------- | --- | ---------------------- | --------------------------------- |
| **A 级** | 高精度 | 太阳系 10 个天体             | JPL 近似根数，1800–2050 年内 **优于 1 角分** |
| **B 级** | 中精度 | 有倾角测定的系外行星（凌星法）        | 轨道形状/周期真实，**瞬时相位为假设值** M(J2000)=0 |
| **C 级** | 低精度 | 无倾角数据的系外行星（RV 法，约 60%） | 轨道方向假设 i=0，**瞬时位置为假设值**           |

### 什么是真实的，什么是假设的？

| 项目            | 状态        | 说明                    |
| ------------- | --------- | --------------------- |
| 太阳系行星轨道与位置    | ✅ 真实三维    | JPL 根数 + 世纪变率修正       |
| 系外行星轨道形状（a/e） | ✅ 真实      | 来自实测数据                |
| 系外行星公转周期      | ✅ 真实      | 来自实测数据                |
| 系外行星瞬时位置      | ⚠️ 假设相位   | M(J2000)=0 可复现假设值     |
| 相对运动分析        | ✅ 真实计算    | 会合周期/距离/速度均真实         |
| 天象推演          | ✅ 真实计算    | 按地心视黄经解析求根            |
| 科研计算          | ✅ 真实拟合/计算 | RV 反演、测光、恒星模型均有单元测试验证 |

> **科研模块自测通过**：RV 注入-恢复偏差 <1%；地球平衡温度 254.6 K（标准值）；地球大气标高 8.36 km（实测约 8.4 km）。

### 物理合规性验证

核心物理计算经过多轮全面审计验证，**未发现严重物理 bug**，覆盖开普勒轨道、能量守恒、角动量守恒、天象推演、科研计算等 40+ 项物理场景：

| 验证项         | 结果          | 说明              |
| ----------- | ----------- | --------------- |
| 单元测试        | ✅ 124 项全部通过 | pytest 自动化测试    |
| 能量守恒        | ✅ 浮点精度内     | 纯二体轨道能量恒定       |
| 角动量守恒       | ✅ 浮点精度内     | 轨道角动量矢量恒定       |
| vis-viva 方程 | ✅ 精确验证      | 速度-距离关系解析一致     |
| 轨道闭合性       | ✅ 精确验证      | 二体轨道严格闭合        |
| 旋转矩阵正交性     | ✅ 精确验证      | 坐标变换矩阵 R·Rᵀ = I |
| 天象冲日精度      | ✅ 精确验证      | 与 JPL 星历自洽      |
| 物理审计        | ✅ 3 轮通过     | 自定义物理定律全量审计     |

> 测试中观察到的轻微轨道偏差、能量微变等现象，均来自 JPL Standish 近似星历的固有受摄运动特性，并非代码层面的物理 bug。太阳系行星周期与 JPL 平均运动自洽优化列为最高优先级改进项。

## ⚠️ 已知局限

本着科学诚实的原则，以下内容请知悉：

1. **系外行星瞬时位置为假设值** —— 平近点角 M(J2000)=0，仅影响"行星现在在轨道哪个点"，不影响轨道形状与周期
2. **JPL 星历限 1800–2050 年** —— 超出范围误差随时间累积，软件会主动警告
3. **约 60% 系外行星缺轨道倾角** —— 三维轨道方向假设为黄道面内（C 级精度标注）
4. **默认可视化半径放大 1000 倍** —— 真实比例下天体极小（地球约 0.00004 AU），HUD 有明确标注
5. **小行星带与表面贴图为程序化生成** —— 按真实分布特征生成，固定种子可复现，非逐颗实测
6. **科研计算为入门级** —— FITS 支持常用子集、RV 反演为二体模型、主序关系为经验近似，适用于教学与入门科研
